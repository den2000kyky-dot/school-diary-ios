РАЗДАЧА ПРИЛОЖЕНИЯ КЛАССУ ЧЕРЕЗ TESTFLIGHT
===========================================

Стоимость: Apple Developer Program — 99 $/год. Без неё TestFlight
недоступен. Один аккаунт на класс; ученикам не нужен ни Mac, ни ПК.

ЧТО НАДО СДЕЛАТЬ ОДИН РАЗ (на сайте Apple)
-------------------------------------------
1. Оформи Apple Developer Program: https://developer.apple.com/programs/
   (Apple ID, оплата, подтверждение личности — 1-3 дня).

2. В https://developer.apple.com/account/resources/identifiers/list
   зарегистрируй App ID (Bundle ID): com.den2000kyky.schooldiary
   (если поменяешь его — поменяй PRODUCT_BUNDLE_IDENTIFIER в
   SchoolDiary.xcodeproj → Target → Build Settings).

3. Там же, в Certificates, создай сертификат "Apple Distribution":
   - сгенерируй CSR (можно на Windows через OpenSSL, см. ниже);
   - скачай .cer, установи, экспортируй в .p12 с паролем.
   Если Мака нет вообще — можно сделать CSR и .p12 через OpenSSL на Windows:
     openssl req -new -newkey rsa:2048 -nodes -keyout key.pem -out request.csr -subj "/CN=School Diary"
   Загрузи request.csr в Apple → скачай certificate.cer →
     openssl x509 -in certificate.cer -inform DER -out certificate.pem
     openssl pkcs12 -export -inkey key.pem -in certificate.pem -out cert.p12 -passout pass:ПАРОЛЬ
   (openssl есть в Git for Windows: "C:\Program Files\Git\usr\bin\openssl.exe").

4. В https://developer.apple.com/account/resources/profiles/list
   создай Provisioning Profile типа App Store для этого App ID,
   выбери тот же сертификат, скачай .mobileprovision.
   Назови его, например: School Diary App Store.

5. В https://appstoreconnect.apple.com создай новое приложение:
   App Store Connect → My Apps → "+" → New App → iOS, имя "School Diary",
   Bundle ID com.den2000kyky.schooldiary, SKU schooldiary-1.

6. В App Store Connect → Users and Access → Integrations → App Store Connect API
   сгенерируй API Key (роль App Manager). Скачай файл AuthKey_XXXX.p8.
   Запиши: Key ID и Issuer ID.

СЕКРЕТЫ В GITHUB
-----------------
Репозиторий → Settings → Secrets and variables → Actions → New repository secret.
Добавь 7 секретов (base64-строки можно получить командой в PowerShell:
  [Convert]::ToBase64String([IO.File]::ReadAllBytes("путь\к\файлу")) )

  CERT_P12_BASE64    — содержимое cert.p12 в base64
  CERT_PASSWORD      — пароль от .p12 (обычный текст, не base64)
  PROFILE_BASE64     — .mobileprovision в base64
  ASC_KEY_BASE64     — AuthKey_XXXX.p8 в base64
  ASC_KEY_ID         — Key ID (обычный текст)
  ASC_ISSUER_ID      — Issuer ID (обычный текст)
  CERT_NAME          — точное имя сертификата из Keychain Access:
                       "Apple Distribution: Имя (TEAMID)"
  PROFILE_NAME       — имя provisioning profile, например "School Diary App Store"

КАК СОБРАТЬ И ЗАГРУЗИТЬ
------------------------
1. Сделай push в репозиторий (как описано в ИНСТРУКЦИЯ-БЕЗ-МАКА.txt).
2. Вкладка Actions → "Upload to TestFlight" → Run workflow
   (или сделай тег: git tag testflight-1 && git push origin testflight-1).
3. Через 5-10 минут сборка появится в App Store Connect →
   TestFlight → твое приложение → Builds.

КАК ДАТЬ УЧЕНИКАМ
------------------
TestFlight → External Testing → создай группу "Клас", добавь сборку,
нажми "Add Testers" и введи email учеников (или включи Public Link —
ссылку можно просто кинуть в классный чат). При первом 외нешнем
распространении Apple может попросить краткое Beta App Review —
обычно проходит за несколько часов или дней.

Сборка в TestFlight живёт 90 дней: раз в ~2 месяца запусти workflow
заново (новый push/тег) — ученики получат обновление в приложении TestFlight.
